
Push-Swap est un projet développé en Go.

L'objectif est de trier une liste d'entiers en utilisant deux piles (A et B) et des instructions limitées.

Le programme `push-swap` doit générer une suite d'instructions permettant de trier la pile A avec un nombre d'opérations aussi faible que possible.

Le programme `checker` doit vérifier que cette suite d'instructions permet bien d'obtenir une pile A triée et une pile B vide.

***

### outils utilisés

- Go
- Git
- GitHub


***


## Structure du projet

- `cmd/push-swap/` : programme de tri
- `cmd/checker/` : programme de vérification
- `internal/pushswap/` : fonctionnalités communes aux deux programmes
